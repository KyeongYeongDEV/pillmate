# Medical Domain Context

## 환자 안전 원칙

> "약은 잘못 먹으면 안 됩니다."

PillMate의 모든 응답과 코드는 다음 원칙을 따른다:

1. **정확성 > 빠른 응답**
2. **출처 > 추론**
3. **확실하지 않으면 전문가 상담 안내**
4. **환자 데이터는 최소 권한 원칙**

## 공식 출처

| 출처 | URL | 용도 |
|------|-----|------|
| 식품의약품안전처 의약품안전나라 | https://nedrug.mfds.go.kr | 약 마스터, 병용금기 |
| 대한당뇨병학회 | https://www.diabetes.or.kr | 당뇨 가이드라인 |
| 대한고혈압학회 | https://www.koreanhypertension.org | 고혈압 가이드라인 |
| 대한약사회 | https://www.kpanet.or.kr | 일반 약물 정보 |

응답에 출처를 명시할 때는 위 표의 명칭을 정확히 사용한다.

## 한국 의료 환경 특수성

- **노인 환자**: 65세 이상, 다약제(polypharmacy) 빈발
- **고혈압/당뇨 동반**: 메트포르민, 암로디핀, 아스피린 조합 흔함
- **한약 병용**: 양약과 한약 동시 복용에 대한 주의 (식약처 가이드라인 부족)
- **보호자 문화**: 자녀(40-70대)가 부모(60+) 케어 → N:N 그룹 모델

## 약물 안전 핵심

1. **병용금기 (Drug Interaction)**
   - 식약처 병용금기 목록은 공식 데이터
   - 사전 검증으로 처방전 등록 시 경고
   - 챗봇 응답 전 사전 검증

2. **연령 금기**
   - 노인 주의 약물 (Beers Criteria 한국화)
   - 소아 금기, 임부 금기

3. **용량 계산**
   - 체중/연령 기반 용량은 한국 가이드라인 우선
   - LLM 계산 결과는 검증 없이 사용 금지

## 의료 데이터 보호

| 데이터 | 분류 | 보호 조치 |
|--------|------|-----------|
| 처방전 이미지 | 민감 개인정보 | SSE-S3 암호화, 3년 후 자동 삭제 |
| 복용 로그 | 민감 의료정보 | RLS (Phase 2+), 감사 로그 |
| 진단 추론 결과 | 민감 의료정보 | 환자 동의 후 보호자에 공유 |
| 약 마스터 | 공개 데이터 | 일반 캐싱 가능 |

## 면책 표시 (응답 표준)

모든 의료 정보 응답 끝에:
```
이 정보는 식약처 공식 데이터 기반이며,
정확한 진단과 처방은 의사/약사와 상담하세요.
```

## 환각 방지 패턴

- LLM이 식약처 DB에 없는 약품명을 생성하면 차단
- "일반적으로 안전합니다" 등 일반화 표현 금지
- 신뢰도 < 0.95 → "확인할 수 없습니다" fallback
