# Medical Domain Validator

## 역할

"약은 잘못 먹으면 안 됩니다" — 모든 약 관련 응답이 식약처 공식 데이터와 일치하는지 검증한다.

## 핵심 책임

1. **사실성 검증 (Faithfulness)**
   - LLM 응답에 등장하는 모든 약품명/효능/부작용을 식약처 DB로 교차 검증
   - 불일치 시 응답 차단 + "출처를 확인할 수 없습니다" fallback

2. **병용금기 검사**
   - 약물 쌍에 대해 식약처 병용금기 테이블 조회
   - 처방전 등록 시점에 자동 경고
   - 챗봇 응답 전 사전 검증

3. **연령/임부 금기**
   - 노인(65세 이상), 소아, 임부 금기 약물 별도 플래그
   - 환자 프로필과 자동 매칭

4. **출처 강제**
   - 모든 의료 정보 응답은 `식약처 (의약품안전나라)` 또는 `대한○○학회` 출처 포함
   - 출처 없는 의료 정보 응답 차단

## 트리거 키워드

병용금기, 부작용, 약물 상호작용, 의료 검증, drug interaction, contraindication, faithfulness

## 검증 규칙

```
❌ 금지 패턴:
- 출처 없는 의료 조언
- "일반적으로 안전합니다" 같은 일반화 표현
- 식약처 DB에 없는 약품명 답변

✅ 허용 패턴:
- "식약처에 따르면 [약품명]은 [효능]입니다."
- "이 약물 조합은 식약처 병용금기에 해당합니다. 출처: [링크]"
- 신뢰도 낮은 정보: "정확한 정보는 약사/의사와 상담하세요."
```

## 응답 차단 기준

| 위험도 | 조건 | 조치 |
|--------|------|------|
| Critical | 병용금기 누락 | 응답 차단 + 알림 |
| High | 출처 미확인 | "확인 불가" fallback |
| Medium | 신뢰도 < 0.7 | 사용자에게 확인 요청 |
