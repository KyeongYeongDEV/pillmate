# PillMate 우선순위 로드맵 (컨설턴트 감사)

> AI TIP #2 적용 (2026-07-10). Fable(CTO)이 오늘 이유를 쓰고, 하위 모델/패널이 내일 그대로 실행한다.
> 원칙: 순위 = 가치(출시 접근도) 기준. 각 항목에 단계·현황·브리핑 포함. 이유는 오늘 안에 정리한다.
> 갱신: 우선순위가 바뀌는 결정마다 이 파일 수정 (문서가 곧 지시서).

## 🎯 목표 상태 (결승선)
스토어에 올라간 PillMate — 실사용자가 카카오로 가입하고, 약봉투를 찍고, 가족과 복약을 공유한다.

## 순위 로드맵 (가치 높은 것 먼저)

### P1. 커밋 체크포인트 ← 지금 여기
- **왜 1위**: 미커밋 250+파일 = 검증된 가치 전체가 휘발성. 사고 한 번이면 몇 주 손실. 다른 모든 작업의 보험.
- **단계**: ①Tier1 변경분(백필·CICD·그룹실시간·인증) 트리오 게이트 → ②논리 단위 분리 커밋 → ③push는 별도 승인
- **현황**: 사용자 승인 대기
- **실행 브리핑**: 게이트는 Reviewer+QA-Claude+Adversarial 병렬, 커밋 묶음은 "홈UX/그룹실시간/CICD/하네스/법적문서" 단위

### P2. 카카오 SSO 실로그인 e2e 확정
- **왜 2위**: 인증 실패 = 신규 유저 0명. 연쇄 픽스(KOE006→파싱→시퀀스) 후 최종 성공을 아직 실측 못 함.
- **단계**: ①시뮬레이터에서 카카오 로그인→홈 진입 ②신규 유저 생성 확인 ③탈퇴→재로그인 reactivate 확인
- **현황**: 환경 전부 세팅됨, e2e 만 남음

### P3. 배포 파이프라인 완주 (deploy-gate G1~G7)
- **왜 3위**: 출시의 물리적 관문. 사용자측 선행(runner 설치·포트 오픈·Secrets 등록)과 병렬 가능.
- **단계**: deploy-gate.md 체크리스트 순서대로. Ops 패널 주관.
- **현황**: G2 일부 점검 시작. 시크릿 로테이션(G1)은 배포 직전.

### P4. 법적 필수 UI (동의 스크린)
- **왜 4위**: 민감정보(§23)·국외이전(§28-8) 별도 체크박스 없이 출시 = 위법. 문서 초안은 완료, UI 만 남음.
- **단계**: ①신규 유저 첫 로그인 후 1회 동의 스크린(isNewUser 활용) ②BE 동의 이력 저장 ③약관 URL 호스팅

### P5. 잔여 버그 스윕 + 스토어 준비
- **왜 5위**: P1~P4 가 끝나야 의미. TestFlight/심사 메타데이터, APNs(실기기 푸시), 스크린샷.

## 🛑 멈춰야 할 3가지 (이유 상세)

1. **새 기능 추가를 멈춰라** — 지금 기능 폭은 MVP 를 이미 넘었다(인사이트 로테이션·그룹 실시간·최근검색 등). 추가 기능 1개의 가치 < 미커밋 리스크 1일. 새 아이디어는 이 파일 하단 백로그에 적고 출시 후 회수.
2. **하네스 개선을 멈춰라** — 룰 10개·도구 3개·스킬 12개로 이번 주 충분히 강화됐다. 하네스는 수단인데 최근 세션에서 목적이 되는 경향. 다음 하네스 작업은 "실사고 재발" 때만.
3. **QA-Gemini 복구 시도를 멈춰라** — function calling 불안정으로 이미 disabled. Adversarial 이 대체 중. 복구 시도는 시간 소모 대비 이득 없음. 출시 후 재평가.
