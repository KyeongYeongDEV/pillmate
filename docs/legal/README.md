## ★ 본 서비스 핵심 이슈 (검토 시 반드시 확인)

1. **민감정보(건강)**: 복약 정보·처방전은 개인정보보호법상 민감정보 → **별도 동의** 필수.
2. **국외이전**: 처방전/약봉투 이미지가 **Google Gemini(미국)** 로 전송(OCR) → 국외이전 고지+동의 필수.
3. **처리 위탁(수탁자)**: AWS(저장), Google(OCR), OpenAI(임베딩), Kakao(로그인), Firebase/FCM(푸시), Sentry(에러).
4. **주민번호**: 원칙적 미수집 (감지 시 등록 차단 구현됨). 방침에 "주민번호 미수집" 명시.
5. **파기**: 탈퇴 시 soft delete + PII 익명화(구현됨), 의료 데이터 3년 보관 후 파기.
